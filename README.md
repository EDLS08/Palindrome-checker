# Palindrome Checker

A Java console application that checks whether a word or phrase is a palindrome.

## Behavior

- Reads a full line from standard input.
- Ignores letter case, spaces, punctuation, and diacritical marks.
- Reverses the normalized text and compares it with the normalized input.

## Requirements

- JDK 8 or newer.

## Run

From the repository root:

```bash
javac -d out src/PalindromeChecker.java
java -cp out PalindromeChecker
```
